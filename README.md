# AAM Replication — Arguments that Alter Minds

Palta et al. (2026), in "Arguments that Alter Minds: LLM Rationales Sway Human (and LLM) Notions of Plausibility," show that LLM-generated rationales systematically shift how both humans and LLMs rate the plausibility of answer choices. We replicate this LLM-only effect on a subset of the original data, then test whether it is amplified in cybersecurity advisory scenarios — where genuine ambiguity (the same behavior can appear benign or malicious) may make LLMs more susceptible to confident-sounding rationales, not less.

**Paper:** Palta, Rankel, Wiegreffe & Rudinger (ACL 2026)
**Original dataset/code:** https://github.com/shramay-palta/AAM

## Pipeline

The pipeline has two steps (Step 1 is skipped when using the prepared data, which includes GPT-4o-generated rationales from the paper):

1. **Rationale generation** (Prompts A.1–A.2, temp=1) — for each `(question, choice)` pair, generate a PRO rationale (arguing for plausibility) and a CON rationale (arguing against). *Skipped when using `data/prepared.csv` — rationales are pre-generated by GPT-4o as in the original paper.*
2. **Plausibility rating** (Prompts A.3–A.6, temp=0.1) — rate each pair under four conditions: NO rationale, PRO only, CON only, PRO+CON. Ratings use a 1–5 Likert scale (Impossible → Very Likely).
3. **Analysis** — measure mean rating shift per condition vs. the NO baseline (Δ), chi-squared tests, and OLS regression for anchoring effects.

## Datasets

| File | Rows | Description |
|---|---|---|
| `data/prepared.csv` | 200 | Full replication set — 50 SIQA + 50 CQA questions, gold + distractor pairs, pre-generated rationales from paper |
| `data/prepared_test.csv` | 20 | Test subset — 5 SIQA + 5 CQA questions, for fast iteration |
| `data/siqa_sample.csv` | 16 | Original hand-crafted sample (deprecated) |

SIQA and CQA source data (with GPT-4o rationales and human ratings) from https://github.com/shramay-palta/AAM — run `prepare_data.py` to regenerate `prepared.csv` from it.

## Models

Run locally via Ollama. Rationale generation uses temp=1; rating uses temp=0.1 (per paper's non-OpenAI setting).

- `qwen3.6:35b` — primary Qwen
- `gemma4:31b` — secondary
- `deepseek-r1:32b` — reasoning model (tests whether CoT resists manipulation)

## Usage

```bash
# Prepare data from the AAM repo (run once)
python prepare_data.py --aam-dir "/path/to/AAM" --output data/prepared.csv

# Test run on 10-question subset (fast)
python run_pipeline.py --model qwen3:32b --input data/prepared_test.csv --skip-rationale-gen

# Full replication run
python run_pipeline.py --model qwen3.6:35b gemma4:31b deepseek-r1:32b \
    --input data/prepared.csv --skip-rationale-gen

# List available local models
python run_pipeline.py --list-models
```

Output CSVs are written to `results/` with columns: `question, choice, condition, rating, rating_raw, model, answer_label, dataset`.

## Project Structure

```
data/            — Input CSVs
  prepared.csv       Full replication set (200 rows)
  prepared_test.csv  10-question test subset (20 rows)
pipeline/        — Ollama client, rationale generation, plausibility rating
prompts/         — Exact prompt templates from Palta et al. (2026) Appendix A
results/         — Output CSVs (gitignored)
prepare_data.py  — Reshapes AAM source data into pipeline-ready format
run_pipeline.py  — Entrypoint
```
